# Documentation figures

All figures are generated by [render_documentation.py](../../scripts/render_documentation.py)
using NumPy/Matplotlib. Run `python scripts/render_documentation.py` from an installed
checkout. The [guide](../GUIDE.md#reproduce-the-figures) lists dependencies.

| Figure | Source and intended reading | Vector original |
| --- | --- | --- |
| [Research workflow](research-workflow.png) | Schematic; distinguishes implemented synthetic models from proposed experimental models | [SVG](research-workflow.svg) |
| [Synthetic trajectories](synthetic-trajectories.png) | Five illustrative draws with latent endpoints and observed coordinates; independent axes, missing segments left broken | [SVG](synthetic-trajectories.svg) |
| [Observation effects](observation-effects.png) | Same latent Brownian draw with controlled exposure/noise/missingness changes | [SVG](observation-effects.svg) |
| [Benchmark results](benchmark-results.png) | Saved same-dataset accuracy intervals and classical coverage-risk curves, split separately | [SVG](benchmark-results.svg) |
| [Stress identifiability](identifiability-stress.png) | All 40 nonempty stress bins with accuracy intervals/counts; no interpolation | [SVG](identifiability-stress.svg) |

The [manifest](figure-manifest.json) preserves exact illustration parameters,
random seeds, simulator/library versions, renderer hash and summary input hashes.
Numerical examples come from the project's unchanged simulator. They are not
microscopy screenshots, experimental tracks, trained predictions on the illustrated
paths or AI-generated scientific images.

Benchmark figures read the frozen [synthetic summary snapshot](../results/20260905/README.md).
Read its uncertainty and provenance limits before reusing a plot. No result was
retrained, tuned or selected based on documentation aesthetics. PNG files are
GitHub previews; SVG files retain scalable text/geometry. Assets follow the
repository license. Keep the synthetic designation and scientific captions when
reusing them.
